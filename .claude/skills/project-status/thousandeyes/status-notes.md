# Project Status Notes

Use this file to keep a running log of your project status. Add a new dated entry each time you update progress, blockers, risks, or next actions.

## Status entry format

- Date: YYYY-MM-DD
- Project: <project name>
- Scope: <what this update covers>
- Progress: <brief summary of what was done>
- Completed: <recent achievements>
- Blockers: <current obstacles>
- Risks: <known or emerging risks>
- Next actions: <immediate next steps>
- Due dates / milestones: <key dates>
- Notes: <important context or assumptions>

## Example entry

- Date: 2026-06-09
- Project: Claude project status helper
- Scope: Create a reusable skill and note system for project updates
